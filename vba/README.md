# VBA Uploads

Ablage für VBA-Artefakte in diesem Repo.

- `vba/modules/` für exportierte VBA-Module (`.bas`)
- `vba/workbooks/` für zugehörige Excel-Dateien (`.xlsm`/`.xlsx`)

## Wenn Upload im Chat nicht funktioniert

### `.bas`-Dateien
Sende den Inhalt als Codeblock im Chat – ich lege daraus die Datei im Repo an.

### Excel-Dateien (`.xlsm`/`.xlsx`)
Wenn du die Datei hier nicht hochladen kannst, nutze eine dieser Optionen:
1. Lokal ins Repo legen und pushen (Pfad: `vba/workbooks/`).
2. Datei als `.zip` packen und versuchen, die ZIP hochzuladen.
3. Einen Download-Link teilen (z. B. OneDrive/SharePoint), dann kann ich den Zielpfad und Dateinamen im Repo vorbereiten.

Für große Workbooks ist Git LFS empfehlenswert.
